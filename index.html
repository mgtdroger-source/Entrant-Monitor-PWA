Tracking Monitor PWA v0.17
Overview

The page loads the uploaded rally route and entrants from the shared Tracking link, then reads the latest positions from the Google Tracking sheet every 15 seconds.

Main buttons

Entrants opens All Entrants and Controls views.

Settings controls marker size, marker labels, default trail length and Control zoom.

Help opens this guide.

Entrant colours

Green — current position.

Orange — delayed or stale report.

Grey — past the selected control.

Red — selected entrant.

Refreshing

Tracking data refreshes automatically every 15 seconds. No manual refresh is required.

The map status pill appears only when a route, connection or tracking-read problem needs attention.

Install

When opened in a browser, use the green Install button to add Tracking Monitor to the device. The last valid shared event configuration is retained for launching the installed app.
